# Paper Extraction Rules

## Papers from 2009–2014

Extract ALL of the following:

```
Q1(a) Q1(b) Q1(c)
Q2(a) Q2(b) Q2(c)
Q3(a) Q3(b) Q3(c)
Q4(a) Q4(b) Q4(c)
Q5(a) Q5(b) Q5(c)
```

Extract the official mark scheme for every extracted question.

## Papers from 2015–2025

The paper pattern changed. From this range:

**DO NOT collect:** Q1(a), Q1(b)

**DO collect:**

```
Q1(c) Q1(d)
Q2(a) Q2(b) Q2(c)
Q3(a) Q3(b) Q3(c)
Q4(a) Q4(b) Q4(c)
Q5(a) Q5(b) Q5(c)
```

Extract the official mark scheme for every extracted question, verbatim.

## General

- Both 2059/01 (O Level) and 0448/01 (IGCSE) follow the same extraction pattern for
  their respective year ranges — confirm paper code and year before applying a rule
  set; if either is unclear, ask.
- If a paper's structure doesn't match the expected pattern for its year (e.g. a
  transition-year paper), stop and ask before extracting.
