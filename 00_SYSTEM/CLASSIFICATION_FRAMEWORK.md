# Chapter Allocation Framework

Every question belongs to exactly **one** Primary Topic. Optional Secondary Tags
(free text, e.g. Causes, Importance, Consequences, Political, Economic, Religious,
Educational, Leadership, Successes, Failures, Comparison, Features, Reforms,
Constitution, Foreign Policy, Domestic Policy) may be added for search. A question
must never physically appear in more than one topic file.

Topic folder/file naming mirrors the numbering below — see `questions/INDEX.md` for
the live file map.

## Overlap handling

If a question overlaps multiple chapters, do not decide automatically. Present:

- Suggested Primary Topic
- Other Possible Topics
- Clickable options, e.g.:
  - Allocate to Ayub Khan
  - Allocate to Yahya Khan
  - Allocate to Multiple Regime Questions
  - Allocate elsewhere (specify)
  - Unsure

Then **stop** and wait for a decision.

## Future flexibility

This taxonomy may be changed — chapters created, renamed, merged, split; questions
moved; tags added — without ever losing the original verbatim question, mark scheme,
metadata, or audit/version history. Any restructuring is itself logged as a new
version in `04_VERSION_HISTORY.md`.
